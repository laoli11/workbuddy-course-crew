# 教学法规范（Teaching Spec）

> 本规范是「课程制片团」写课、洗稿时的**强制约束**，与 production-spec 并列。
> 定位：我们的观众是**小白**——没写过代码、电脑玩得不溜、第一次听说 AI。观众能感觉到老师的耐心，是课程的第一竞争力。
> 方法论吸收自：claudemy（每课一任务一条规则）、ra-洗稿（去AI味+钩子）、Genie Learn（术语解释）、socratic-tutor（子技能分解）。

## 一、总则（谁在看我们的课）

1. 默认观众**什么都不懂**，不假设任何先验知识。
2. 每个新术语第一次出现，必须用一句大白话解释。
3. 每个操作必须拆成一步一步的步骤链，**不跳步**。
4. 语气有耐心，让小白敢跟着做、做错了也敢再来。

## 二、SOP 式任务分解（每步教学法的标准范式）

每个操作任务按「步骤链」讲，**每一步必须满足四要素**：

| 要素 | 内容 | 示例（教下载 WorkBuddy） |
|---|---|---|
| 做什么 | 一句话说清这一步的目标 | 第一步，打开浏览器 |
| 在哪操作 | 精确到按钮/位置 | 浏览器就是你看网页的软件，Edge 或 Chrome 都行 |
| 为什么 | 让观众理解而不只是模仿 | 我们要去百度搜官网，别的下载站可能带捆绑 |
| 注意/避坑 | 这一步容易错的地方，提前说 | 拼写是 w、o、r、k、b、u、d、d、y，buddy 是"伙伴"的意思，别打成 body |

**范例（教下载的标准拆法）**：

- 第一步：打开浏览器（Edge 或 Chrome 都行）
- 第二步：打开百度，搜索 WorkBuddy（拼写逐字强调）
- 第三步：认官网（带"官网"标识的第一条）
- 第四步：按系统下载（Windows 电脑点 Windows 版，苹果电脑点 Mac 版）
- 第五步：安装位置（**重点避坑：别装 C 盘，改 D 盘**）

> 检查标准：观众照着念，一步都不会卡住，才是合格的步骤链。

## 三、术语即解释（每个新词第一次出现必须解释）

- 新术语（Agent、API、模型、知识库、上下文、连接器）第一次出现必须配一句大白话：
  - 错误示范："这个其实就是系统提示词。"
  - 正确示范："这个其实就是系统提示词——你就把它当成每次对话开头，官方提前帮你写好的那句话。"
- **禁止**连续抛出多个未解释的术语。

## 四、每课一个可落地小任务（学完就能做）

- 每节课结尾给一个 **2–5 分钟能完成**的练习，具体、可检验（做完能看到结果）。
- 示例："今天学完，你试着做这件事：把 WorkBuddy 的默认存储路径改到 D 盘，改完截图发到群里。"

## 五、每课一条「记住」规则

- 每课的精华浓缩成一条规则，用「记住一句话」引出。
- 观众记不住全部，但要能记住这一条。
- 示例："记住一句话：存储路径别放 C 盘，会越用越大。"

## 六、开场钩子 + 耐心语气

1. **开场 30 秒内说清三件事**：这节课解决什么问题、学完你能做什么、有多快能学会。
2. **耐心语气词汇**（多用）：
   - "别急，跟着我一步一步来"
   - "这里容易出错，我们慢一点看"
   - "没做对也没关系，关掉重来一遍就行"
   - "如果你是 Windows 电脑，看这里；苹果电脑，看这里"
3. **禁用词**（让小白有压力，一律删）：
   - "很简单""不用说""大家都知道""随便点一下就行"
   - 替换："跟着我点""咱们一起看""这里就一个小设置"

## 七、结尾呼应

- 结尾回顾三点：这节课你学会了什么（呼应开头目标）。
- 一句鼓励 + 下节课预告。

## 八、洗稿时的加工清单（逐字稿 → 口播稿必查）

- [ ] 每个操作步骤是否满足「做什么/在哪/为什么/避坑」四要素，缺的补上
- [ ] 新术语是否都解释了
- [ ] 有没有"很简单"类词汇，全部替换成耐心表达
- [ ] 有没有跳步（观众会卡住的地方），补中间步骤
- [ ] 结尾有没有可落地小任务 + 一条「记住」规则
- [ ] 开场 30 秒是否说清了"解决什么/学完能做什么"

```markdown
### 学习目标（学完能做什么，2-3 条）

### SOP 步骤链（主要操作，每步四要素）
第1步：做什么 / 在哪 / 为什么 / 避坑
第2步：...
### 核心术语（要解释的）
- 术语 → 大白话解释
### 避坑点（重点强调）
- 
### 课后小任务（2-5分钟可完成）
- 
### 记住一句话
- 
```
