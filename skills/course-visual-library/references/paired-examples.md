# 好坏成对样例（Paired Examples）

> 同一句口播，做对和做错各长什么样。做新段前先看这组对照，别重踩。

## 样例 1：概念动画「AI 从会聊天到会干活」（WB-C01 进化蜕变）

口播原文：*"以前的 AI 你问一句它答一句；现在的 WorkBuddy，你一句话，它自己就把活干完了。"*

### ❌ 做错（几何拼图版，第一课初版踩过）

| 问题 | 表现 |
|---|---|
| 几何拼图 | 机器人用 div 方块拼出来，像 PPT 图形 |
| 无质感 | 无光晕、无胶片颗粒，纯色块发"塑料感" |
| 硬切线性 | 元素直接淡入淡出，无缓动、无弹性、无错峰 |
| 文字无层次 | 标题和说明一样大，关键词不高亮，扫一眼抓不到重点 |
| 字幕遮挡 | 标题压在底部字幕区，字幕两行被挡 |

### ✅ 做对（OpenFilm 改进版，animation-spec + 本库标准）

| 改进 | 做法 |
|---|---|
| SVG 渐变机身 | 机器人用 SVG 渐变 + 发光眼睛/微笑 + 呼吸悬浮，不是方块拼图 |
| 能量爆发 | 出现时中心闪光 + 3 层扩散光环 + 24 颗迸发粒子（光晕不过曝）|
| 胶片颗粒 | 全片叠 opacity 0.05 细噪点，去"矢量塑料感" |
| 弹性缓动 | 气泡 easeOutBack 弹性缩放、汇聚收缩过渡成机器人、元素错峰进场 |
| 排版层次 | 标题 70px 主体 + 96px 关键词「会干活」青→金渐变高亮发光，大小+颜色双重层次 |
| 字幕避让 | 标题最低点 y≤802，字幕区 y≥864 零侵入 |

## 样例 2：文字强调「三个要点」列表（WB-T01 要点列表）

口播原文：*"WorkBuddy 有三大能力：帮你写、帮你查、帮你干。"*

### ❌ 做错
- 三个要点一次性整块弹出来，没有随口播逐个点亮
- 要点卡纯白底黑字，无毛玻璃质感
- 序号和正文一样大，分不清主次

### ✅ 做对
- 毛玻璃卡片错峰浮现（60–120ms 间隔），**说到哪张亮哪张**，其余变暗
- 序号徽章大、正文中、说明小，三级层次
- 当前要点关键词高亮（金/青），观众视线跟着走

## 通用铁律（两例共通）

1. 画面主体最低点 ≤ y840，字幕区 y≥864 零侵入
2. 发光先压暗再叠辉光，防过曝发白
3. 元素错峰进场，禁整体同时出现
4. 关键词随配音逐个点亮，不整句同时亮
