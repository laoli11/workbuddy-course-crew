# 动画专项约束规范（Animation Spec）

> 本规范是「课程制片团」动画产出的**强制约束**，与 production-spec 并列。
> - production-spec 管**正确性**（确定性渲染、字幕避让、音效音量、不遮挡）
> - **本规范管「丝滑与美感」**——让动画质感对标 Claude Opus 5.5 / Codex 出片水准
> 方法论来源：《全网最细，带你拆解 Opus 5.5 做视频》及各开源 skill 的最佳实践。

## 一、核心认知（先想清楚再动手）

1. **丝滑不是软件给的**：Claude/Codex 用「写代码 → 渲染成视频」产出画面，同样的 HTML/CSS/JS 我们也在用。差距在**约束**，不在工具。
2. **好动画 = 设计规范 + 严格工作流 + 参考实现**，三者缺一不可。
3. **一句话出片是表象**：背后是扎实的提示词/脚本工程 + 技术栈选型 + 迭代验证。禁止指望一句描述直接得到成片。

## 二、工作流铁律（最高优先级，违反即返工）

### 1. 先方案，后渲染
动手写渲染代码前，**必须先出 2–3 个风格方案**给用户选：
- 每个方案含：一段 5–8 秒的**静态预览帧/拼图** + 配色 + 动效风格 + 排版方向
- 用户选定后，**才逐帧渲染**。禁止直接渲全片。

### 2. 先样片，后全片
- 先出 **30 秒（或单段）样片**确认质感，用户点头后再铺全片。
- 禁止跳过样片直接做整集。

### 3. 分镜表 → 动画规范 → 逐帧渲染（PDoomVideo 结构）
每段动画按三段式推进：
1. **分镜表**：每镜头「画面 / 时长 / 动效 / 音效点」，先列全
2. **动画规范**：色彩、缓动、字体、粒子规则、光晕/颗粒参数，集中定义
3. **渲染脚本**：最后才写代码，逐帧渲染

### 4. 可「指着画面改」
动画参数必须**集中、可局部调整**（配色、字号、动效时长各归一个常量/配置），改一处不牵连整体，支持"指着画面改"式的迭代。

## 三、视觉质感规范（电影感来源）

### 1. 两个必加滤镜（"塑料感"变"电影感"的关键）
- **光晕 Bloom/Glow**：发光元素叠加柔光，营造高级感。⚠️ 先压暗实色再叠辉光，防过曝发白。
- **胶片颗粒 Film Grain**：叠加细颗粒噪点（SVG `feTurbulence` 或 CSS noise），去"矢量塑料感"，增加质感。
  - 颗粒强度：轻微（opacity 0.04–0.08），不可看到明显噪点。

### 2. 七大技术栈选型（按画面需求选，不要只会一种）
| 需求 | 技术栈 |
|---|---|
| 排版/文字动效 | HTML/CSS |
| 2D 粒子/图形 | Canvas |
| 手绘质感 | 手绘笔刷 |
| 光效/材质 | Shader（GPU）|
| 3D 场景 | Three.js |
| 数学/教学动画 | Manim（3Blue1Brown）|
| 电影级 3D | Blender |

### 3. 缓动与节奏（固定曲线，禁随手写）
- 主曲线（进入/落定/文字出现）：`bezier(.22, 1, .36, 1)` ease-out
- 对象搬移（缩放/位移/换位）：smoothstep
- 章节擦出：`bezier(.65, 0, .2, 1)`
- 回弹：`1 − e^(−8p)·cos(9p)`，0.5–0.8 秒，**只在"砸下来"时用，默认不用**
- 无过冲落定 `settle()`：0→1 平滑到位不回弹，入场和胶囊落定默认用它（防"进来抖一下"）
- 逐字输入 `typed()`：标题约 10 帧/字、正文 5–7 帧/字（60fps）
- **错峰进场（stagger）**：多元素按 60–120ms 间隔依次进入，不机械等距
- **一个组件只做一个主动作**，动作来自"观众要看懂的变化"，不堆砌特效

### 4. 音效音量（固定）
- 常规音效音量 0.5，打字音 0.4，**不超过 0.5**
- 一个主动作配一声；同一时刻多动作只给主交接一声
- 不按每个字、每帧触发

### 5. 镜头运镜（反 PPT，静止帧结构上不允许出现）
- **每场景一条极缓推拉相机曲线**：默认给画面一条极缓推进/拉出的镜头运动，替代"静止画面"（参考 video-talkcraft 七层模型）。
- **让位生命周期**：旧对象退后缩小保留上下文，新对象接管阅读区；交接靠同一对象连续变形，不硬切。
- **六式转场**：淡入淡出、胶囊放大成黑幕开窗、卡片变形成窗口、页面压线展开、前后景深交换、输入框匹配剪辑。
- **默认关闭**：idle 微动、环境呼吸、脉冲——运动系统做减法，一条相机曲线 + 让位就够。

### 6. 质感工具件 kit（统一调用，禁手写近似）
- **Grain** 胶片颗粒：细噪点 opacity 0.04–0.08
- **Vignette** 暗角：四周轻微压暗，聚焦中心
- **SpeedBlur** 速度模糊：自写时间采样模糊（替代通用 CameraMotionBlur，后者近静止帧发灰染黄）
- **softShadow** 柔和阴影 + **surface** 表面：建立层级

## 四、文案与配音规范（"丝滑"的另一半）

1. **字级配音同步（最高优先级）**：动效节拍**锚在确切的字上**，不是句子上。用字级时间戳（每字 {字,起,止}）驱动画面——关键词说到第几个字，画面就变到对应状态（参考 video-talkcraft，字级偏差中位 20–40ms）。禁"整句开始才整体动"。
2. **字幕按字/词对齐**：关键词随配音**逐字点亮**，不整句同时出现；重点词高亮（金色/强调色）。
3. **口播文案节奏**：短句（≤20 字）、口语化、有停顿，禁念稿腔。

## 六、质量自检清单（交付前必查）

- [ ] 已先出方案给用户选，再渲染
- [ ] 已先出样片确认，再铺全片
- [ ] 加了光晕（不过曝）+ 胶片颗粒
- [ ] 缓动丝滑（无线性/硬切），元素错峰进场
- [ ] 字幕按字/词对齐配音，关键词逐个点亮
- [ ] 动画节奏踩在配音停顿/重音上
- [ ] 参数集中、可指着画面改
