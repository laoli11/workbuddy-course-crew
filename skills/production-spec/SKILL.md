# 课程制片约束规范（Course Production Spec）

> 本规范是「课程制片团」全体成员的**强制约束**，任何产出必须符合。违反即返工。
> 方法论吸收自确定性视频引擎（vibe-knowledge-film/engine.md）：一帧一画、时间驱动、先拼图后成片。

## 一、总则

1. 目标：产出**可发布**的 WorkBuddy 课程视频，质量对齐专业录课水准，不敷衍。
2. 讲师人设：团队售后老师「尧哥AI」，口语化、亲切、不装腔。
3. 所有输出语言与用户原始需求一致（默认简体中文）。
4. 每一步产出落盘为文件，供下一步读取（文件接力），不靠记忆。

### 确定性铁律（最高优先级）

- **每一帧只由时间 t 决定**：同一 t 永远画出同一画面，无论渲染顺序、机器、次数。
- **禁止** `Math.random()`、`Date.now()`、墙钟时间、跨帧累积状态。随机一律用**带种子的确定性发生器**（seeded rng）。
- 模拟/粒子要先算完存表，每帧按时间查表，不逐帧积分。
- 渲染后必须做**一致性自检**（对照两帧/两轮是否一致）。

## 二、内容规范（内容编导）

- 逐字稿 → 口播稿：去口语填充词、修口误病句、压缩重复，**保留课程骨架与观点**。
- 口语化：去 AI 味，加「咱们 / 嘛 / 呢 / 说白了」，**长句拆到 20 字以内**，去掉书面连接词。
- 公司名、产品名、数字、人名、观点**原样保留，一字不改**；涉及竞品时公允，不下主观断言。
- 分镜脚本：每段标注「口播 / 概念动画 / 录屏实操」+ 画面描述 + 预估时长；动画段必须写明**风格关键词**（默认「科技感：深色渐变 + 发光」）。
- 每段定义**本地时间** `lt = t - 该段起始`，段内全部用 lt，整段挪动只改一个数。

## 三、配音规范（语音配音）

- 音色：**克隆讲师本人音色**（朗读稿约 60 秒，环境安静、距麦克风约 15cm、自然平稳、不播音腔）。
- 合成参数范围：语速 0.9–1.2、音量 2–5、音调 -3 ~ +3；数字与拼写按 TTS 稿规范念。
- 每段配音按分镜分段输出，附 SRT 字幕（时间轴对齐）。

## 四、音效与配乐规范（语音配音选材，视频导演合成）

- 配乐：优先 **OpenFilm 免费 CC0 音乐库**（`openfilm get music-search`），tempo 适中、energy 2–3、可循环。
- 音效：转场、强调、按钮等用 **OpenFilm 音效库**（`openfilm get sfx-search`，约 5400 个 CC0）。
- **音效事件表**：音效按「(时刻, 名字)」记录成事件表，同一时刻同名只记一次；合成阶段统一叠加，不逐个硬编码。
- 音量关系：**人声为主，配乐为背景**，配乐音量不高于人声的 20%，关键处可淡出。
- 成片响度：**-14 LUFS**，true peak ≤ -1 dBTP。
- 无版权风险：只用 CC0 库或用户自备素材，**禁止**引入未授权音乐。

## 五、画面规范（视频导演）

- 画幅：1920×1080，30fps（竖屏需求除外）。
- 动画风格：科技感（深色多层渐变 + 发光 + 玻璃拟态 + 粒子），**禁止几何纯色块拼图**。
- 动画时长：每段 5–8 秒。
- **缓动约定**：进场 `easeOutCubic`，弹出 `easeOutBack`，位移 `easeInOutCubic`；禁止生硬线性。
- **镜头衔接**：相邻镜头/元素时间窗**重叠半秒各自淡入淡出**，禁止 `if (t < x) a(); else b();` 式硬切。
- 录屏：OBS 实操，避坑点要**停顿强调**、局部放大。
- 动画为**无声段**，配音 + 配乐 + 音效在合成阶段对齐。

## 六、字幕规范（视频导演合成）

- 字幕区：**纵向 80%–95% 只属于字幕**，画面主体最低点不得低于 y≈840（1080p）。
- 关键词强调用高亮色（如金色 / 强调色），不用整句加粗。
- 相邻两句之间留 **0.15–0.3 秒**空隙。
- 字幕**永远最后叠加**，压在一切画面之上。

## 七、合成与交付规范（视频导演 + 主理人）

- 音画对齐：按分镜时间轴，把配音、配乐、音效、动画、录屏对齐渲染成片。
- 渲染走 OpenFilm（或 Remotion）；ffmpeg 复用 `@remotion/compositor-*`；chromium 走国内镜像（`PLAYWRIGHT_DOWNLOAD_HOST=https://cdn.npmmirror.com/binaries/playwright`）。
- 交付：成片放课程目录 `04_成片`，录屏/素材放 `03_素材`，录完把文件夹 `_未录制` 改 `_已录制`。

## 八、渲染与迭代工作流（视频导演）

**先看小样，再渲成片，禁止一上来渲全片：**

1. 先**截帧**（关键时刻）或**拼图**（全片均匀 16 帧拼一张）快速看效果。
2. 满意后**渲片段**（某段时间）核对节奏与转场。
3. 最后才**渲全片**；长片**分片并行渲染再无损拼接**。

## 九、工程踩坑清单（全员必读，违反即返工）

- **辉光过曝**：发光越亮光晕越大，实心大色块先压暗一档再叠辉光，否则发白糊成一团。
- **硬切**：镜头切换必须重叠淡入淡出，不得硬切。
- **半透明叠加**：线框/粒子用加法混合（add）；实体叠实体用整组淡，避免重叠处透底。
- **一帧画太多**：上千粒子用最简单的绘制，慢的预处理（取样字形、算模拟）放载入时缓存。
- **文字太长**：定稿前先量最长字幕，中文不超约 1400px，超出即断句。
- **时间写死**：每段用本地时间 lt，整段挪动只改起始一个数。

## 十、协作铁律（全体）

1. 主理人**亲自** TeamCreate 建团队，不得委派。
2. 成员产出**必须 SendMessage 回传主理人**，跨成员信息经主理人中转，不得互相直连。
3. 主理人只编排汇编，**不代写**成员专业产出；成员结论为准。
4. 禁止跳过前序阶段；禁止未完成就进入下一阶段。
5. 每完成一个阶段，向用户**简要通报**进度。
