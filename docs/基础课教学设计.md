# 基础课 7 门教学设计

> 按教学法规范（teaching-spec）生成：每课有学习目标、SOP 步骤链、核心术语、避坑点、课后小任务、记住一句话。
> 用途：洗稿和录制的执行依据；每课录前先看本设计。

## 第01课 入门

### 学习目标（学完能做什么）
1. 自己把 WorkBuddy 下载、安装到电脑上（避开 C 盘坑）
2. 用微信扫码登录，并每天领免费积分

### SOP 步骤链
- 第1步 打开浏览器（Edge 或 Chrome 都行）→ 为什么：我们要去官网下，别的站可能带捆绑
- 第2步 百度搜 WorkBuddy → 拼写逐字：w-o-r-k-b-u-d-d-y（buddy=伙伴，别打成 body）→ 避坑：拼错会搜到别的
- 第3步 认官网 → 带"官网"标识的第一条；保底办法：地址栏直接输 workbuddy.cn（英文点）
- 第4步 按系统下载 → Windows 电脑点 Windows 版，苹果点 Mac 版
- 第5步 安装 → **避坑：安装目录别选 C 盘，改到 D 盘**（停顿强调）
- 第6步 登录 → 微信扫码
- 第7步 领积分 → 左下角"加油站"，每天送 100

### 核心术语
- AI / 大模型：能听懂人话、帮你写东西的软件大脑
- Agent（智能体）：不只是聊天，能自己动手干活的 AI
- 积分：WorkBuddy 里干活的"额度"，用的时候消耗

### 避坑点
1. 拼写 workbuddy 别打成 workbody
2. **安装目录别装 C 盘**
3. 找官网别点进广告仿冒站

### 课后小任务
把 WorkBuddy 装好、登录、领一次积分，截图发群里。

### 记住一句话
下载认官网、安装换 D 盘、每天领积分。

## 第02课 环境配置避坑

### 学习目标
1. 把锁屏运行、技能自动更新、存储路径等关键设置一次配好
2. 理解系统提示词、长期记忆是什么，会用它们让 WorkBuddy 更顺手

### SOP 步骤链
- 第1步 领积分 + 进设置 → 左下角加油站领积分 → 点你的名字 → 设置
- 第2步 权限-允许锁屏运行 → 默认关闭 → 改成"息屏后保持唤醒" → 为什么：锁屏了任务会断；再检查"运行时防止系统休眠"开着
- 第3步 技能自动更新 → 默认关 → 打开 → 为什么：飞书等接口会变，技能要跟着更新
- 第4步 **存储-默认工作空间 → 从 C 盘改到 D 盘** → 为什么：任务/文档/视频全放这，越用越大（重点停顿）
- 第5步 个性化 → 改 WorkBuddy 对你的称呼和它自己的名字 → 顺手
- 第6步 写给 WorkBuddy 的指令 → 把你的一次性要求写这（"回复简洁点"）→ 每次对话它都先看
- 第7步 长期记忆 → 主动说"记住……"让它记你的习惯 → 换新对话也记得

### 核心术语
- 系统提示词：每次对话开头官方预置的那句"身份设定"
- 上下文/短期记忆：聊天记录让 AI 显得"记得"，换窗口就忘
- 长期记忆：AI 手边的小笔记本，换窗口也不丢

### 避坑点
1. 锁屏运行默认关——不开的话人一走任务就断
2. **存储路径默认 C 盘——一定要改**（本课最大坑）
3. 技能自动更新默认关——建议开

### 课后小任务
把默认存储路径改到 D 盘 + 给 WorkBuddy 写一条指令（比如"回复简洁点"），截两张图。

### 记住一句话
存储改 D 盘，指令写进"写给 WorkBuddy 的指令"。

## 第03课 空间与模型

### 学习目标
1. 会用三种模式（办公/开发/设计）新建任务
2. 会按任务类型选模型，知道怎么省积分

### SOP 步骤链
- 第1步 新建任务 → 选模式：办公/开发/设计 → 为什么：模式不同，能用的工具不同
- 第2步 选模型 → 快速（省积分）/均衡/极致 → 为什么：越强的模型消耗积分越多
- 第3步 认识免费模型 → 混元等免费档 → 夜间还有免费时段 → 避坑：不赶时间就选免费/快速档
- 第4步 权限设置 → 默认权限 vs 允许完全访问 → **避坑：完全访问有危险性，小白保持默认**
- 第5步 空间 → 新建空间放项目 → **避坑：先选对空间再对话**，否则文件放错地方

### 核心术语
- 模型：AI 的大脑，有强有弱，用积分换
- 空间：你的项目文件夹，任务都放在里面
- 多模态：除了文字，还能看图、识别图片

### 避坑点
1. 完全访问权限有危险，小白别开
2. **先选空间再对话**，不然文件乱放
3. 不赶时间用免费/快速模型，省积分

### 课后小任务
新建一个"测试空间"，用免费模型跑一个简单任务（比如"帮我写一段自我介绍"）。

### 记住一句话
先选空间再对话，不赶时间用免费模型。

## 第04课 专家技能与定时任务

### 学习目标
1. 分得清专家、技能、连接器是干什么的
2. 会给 WorkBuddy 设定时任务（比如每天自动领积分）

### SOP 步骤链
- 第1步 找入口 → 左上角：专家/技能/连接器三个按钮
- 第2步 理解三者关系（装修比喻）→ 连接器=水电管线（前提）；技能=电工水暖工（手艺）；专家=装修队长（协调）
- 第3步 试一个技能 → 比如"去AI味"→ 三种用法：去试试 / 加号选技能 / 斜杠搜索
- 第4步 设定时任务 → 例：WorkBuddy 积分助手每天定时领积分 → 设置触发时间（如每天上午11点）

### 核心术语
- 连接器：让 WorkBuddy 连上飞书、企微这些外部服务的"插头"
- 技能：一个具体本领（写周报、去AI味）
- 专家：把多个技能打包成的一个"专业角色"
- 定时任务：到点自动干活，不用你盯着

### 避坑点
1. 定时任务的高级代码看不懂就别动（原生开发很复杂）
2. 技能优先用现成的，别自己造轮子

### 课后小任务
给 WorkBuddy 设定一个"每天早上 9 点自动领积分"的定时任务。

### 记住一句话
连接器是插头、技能是手艺、专家是队长；定时任务让 AI 自己干活。

## 第05课 三种知识库

### 学习目标
1. 会把资料交给 WorkBuddy，让它按你的资料回答
2. 知道三种知识库（工作空间/资料库/ima）各自适合什么场景

### SOP 步骤链
- 第1步 方式一·工作空间 → 新建空间 → 拖文档进去 → 选"作为知识库存储" → 为什么：回答就有了依据
- 第2步 方式二·资料库 → 适合多任务多用户 → 两种入库：加号上传 / 对话里直接说
- 第3步 方式三·ima（腾讯的）→ 微信授权 → 下载安装（**避坑：别装 C 盘**）→ 免费 20G + 格式更多
- 第4步 验证 → 新开对话提问，看它是不是按你的资料回答

### 核心术语
- 知识库：你喂给 AI 的资料集合，它按这个回答
- RAG：先查资料再回答的技术（检索增强）

### 避坑点
1. 上传的文档要选"作为知识库存储"，否则只是普通文件
2. ima 安装别装 C 盘

### 课后小任务
把自己的一个文档（比如公司介绍）上传成知识库，然后问一个只有这文档里有的问题。

### 记住一句话
单任务用工作空间、多人共享用资料库、企业级用 ima。

## 第06课 连接微信与企业微信

### 学习目标
1. 会用手机远程指挥电脑上的 WorkBuddy 干活
2. 会连微信助理/企业微信机器人，像聊天一样发任务

### SOP 步骤链
- 第1步 小程序扫码连接 → 左下角手机+电脑按钮 → 勾"允许移动端连接此设备"+"保持唤醒"（避坑：不勾连不上）→ 扫码 → 同账号授权
- 第2步 微信助理（更推荐）→ 左上角"助理" → 设置里选微信 → 扫码连"微信 Cloud Bot" → 像聊天一样发任务
- 第3步 上下文管理 → 聊天记录越长越耗积分 → 默认 6 小时截断（避坑：别让群聊无限刷）
- 第4步 企业微信机器人 → 扫码一键创建 → 可拉群 → @机器人全员用 → 避坑：多次连接会失败，删机器人重连，二维码页别关

### 核心术语
- Cloud Bot：微信里的机器人账号，你给它发消息=给 WorkBuddy 发任务
- 上下文截断：太久之前的聊天记录会被"忘记"，为了省积分

### 避坑点
1. 手机连接前要勾"允许移动端连接此设备"
2. 企微机器人连失败就删了重连，二维码页面别关
3. 群聊里用注意积分消耗

### 课后小任务
用微信给 WorkBuddy 发一条语音任务（比如"把桌面上的图片重命名成今天的日期"）。

### 记住一句话
手机连电脑先勾"允许连接"；微信里像聊天一样发任务。

## 第07课 提示词专讲

### 学习目标
1. 掌握提示词九大技巧，让 AI 一次给对答案
2. 会用"角色/技能/要求/示例/限制"五段框架写结构化提示词

### SOP 步骤链（技巧清单）
- 第1步 说清楚给足上下文 → AI 是个黑盒子，你说的越细它答得越准
- 第2步 少说"也许"多用"必须" → 明确要求，别给它含糊空间
- 第3步 扮演角色 → "你是一个十年经验的 HR" → 回答立刻专业
- 第4步 用分隔符和 Markdown → 把资料和要求分开，AI 看得清
- 第5步 分步执行 → 复杂任务拆步骤，"先做1再做2"
- 第6步 给示例 → 一个例子胜过十句描述
- 第7步 拆分复杂任务 → 一次只让干一件事
- 第8步 内心独白 → "先说出你的思路，再给答案"
- 第9步 检查者角色 → "按清单逐项检查一遍再交"
- 第10步 五段框架 → 角色/技能/要求/示例/限制 组装成完整提示词

### 核心术语
- 提示词：你发给 AI 的那段话
- system/user/assistant：提示词三种角色，系统级优先级最高
- 上下文上限：聊天太长会被截断，所以长任务要精简

### 避坑点
1. 问题含糊，AI 就自由发挥——说清楚
2. 一次塞太多任务——拆分
3. 重要任务别忘让 AI 自检

### 课后小任务
用五段框架写一个提示词（比如"帮我写一份周报"），对比用框架前后的回答质量。

### 记住一句话
角色定身份、要求说清楚、示例给参照、限制防跑偏。
