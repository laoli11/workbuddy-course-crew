# 剪辑专项规范与问题记录

> 本文档记录课程制作中踩过的坑（现象/原因/规避方法）+ 剪辑常见问题清单 + 剪辑常识参数，供「课程制片团」全体成员与后续课程复用，防止重复踩坑。

## 一、本次修复的问题记录（现象 → 原因 → 规避）

### 1. 字幕专有名词被拆断（🔴 严重）
- **现象**：`WorkBuddy` 在字幕换行时被拆成「work」一行 +「body」下一行；人名「尧哥」被拆成「姚」+「哥」。
- **原因**：字幕按字数硬拆句，只保护了「字数」，没保护「英文单词/人名」的完整性边界。
- **规避**：拆句算法必须**保护连续英文字母**（切点不得落在两个英文字母之间）；人名等人名实体同理。已在 `fix_subtitles.py` 实现英文词边界保护 + 人名合并后处理。

### 2. 字幕文字错误（🔴 严重）
- **现象**：`Workbody`（应为 WorkBuddy）、`姚哥`（应为尧哥）、`deepseek`（DeepSeek）、`CodeCodex`（Codex）、`ppt`（PPT）、`excel`（Excel）等。
- **原因**：ASR 语音识别误差 + 未做专有名词修正。
- **规避**：生成字幕后必须过一遍**专有名词修正表**（品牌名、人名、英文大小写）；英文词用 `(?<![A-Za-z])词(?![A-Za-z])` 边界替换（`\b` 在中文边界失效）。

### 3. 概念段用占位卡而非动画（🟡 建议修）
- **现象**：概念讲解段（动画只有 8 秒，配音有 29–82 秒），动画播完只能放「大字占位卡」。
- **原因**：动画时长与配音时长不匹配，且环境 ffmpeg（Remotion/playwright 精简版）缺 `tpad` 定格滤镜。
- **规避**：用「提取末帧 + 图片循环 + concat 拼接」实现**动画定格延长**（动画播 8 秒 → 定格在标题画面铺满配音段）。概念段动画铺满，不留占位符；只有实操环节才用录屏素材。

### 4. 音效抢人声（🔴 严重）
- **现象**：音效 -12~-15.5 LUFS，比配音 -18.1 LUFS 还响 3~6 dB，听感突兀、盖过人声。
- **原因**：音效未按「比人声低 6-8 dB」的标准设定音量。
- **规避**：音效音量应比人声低约 6-8 dB（约 -23 LUFS）；boom 类冲击音效源文件本身已削波（+1.9 dBTP），必须降 8 dB 以上再叠。

### 5. 配音开头突兀（🟡 建议修）
- **现象**：配音突然开口、结尾戛然而止。
- **原因**：合成音频无淡入淡出。
- **规避**：配音加 **0.5-0.6s 淡入 + 3s 淡出**（精简 ffmpeg 无 `afade`，用 `volume='if(lt(t,...),...)'` 表达式实现）。

### 6. 剪映草稿生成后首页不显示（🔴 严重）
- **现象**：草稿文件（`draft_info.json`）生成并加密了，但剪映首页列表里找不到。
- **原因**：生成脚本只创建草稿文件，**没有把草稿注册进剪映的草稿列表索引**（`root_meta_info.json` 的 `all_draft_store`）。
- **规避**：生成后必须手动（或脚本）把草稿条目写入 `root_meta_info.json`；`draft_json_file` 指向新建草稿的 `draft_info.json`，`draft_cover` 留空。剪映开着时需**完全重启**才重新读索引。

### 7. 剪映 11.7 草稿加密回验失败（🔴 严重）
- **现象**：加密时 `decrypt failed: ok_flag=True, output_len=0`，草稿加密失败。
- **原因**：`pyJianYingDraft` 的 aoguai 分支在剪映 11.7 上，`encrypt`（加密）正常、但 `decrypt`（解密回验）签名不兼容。
- **规避**：加密时 `validate_roundtrip=False`（跳过解密回验，只做加密），`isolated=False`（主进程直接调 DLL）。注意：aoguai 分支必须从 GitHub 装（`pip install git+https://github.com/aoguai/pyJianYingDraft.git`），PyPI 原版不支持剪映 6+ 加密。

### 8. 精简 ffmpeg 缺滤镜（🟡 建议修）
- **现象**：`tpad`、`afade` 等滤镜报 `Filter not found`。
- **原因**：Remotion / playwright 自带的 ffmpeg 是精简版，只保留少量滤镜。
- **规避**：定格延长用「提取末帧 + `-loop 1` 图片 + `concat`」；淡入淡出用 `volume` 表达式的 `if` 实现；拼接用 concat demuxer（需统一编码参数）。

## 二、剪辑常见问题清单（剪辑手法守则）

1. **剪辑思维高于软件**：每一刀都要有理由——为什么这里切、为什么这个景别、为什么这个转场。
2. **硬切是大忌**：镜头切换用 J-cut（声音先行 1-2 秒）/ L-cut（声音延续），比声画同时切自然；相邻镜头重叠半秒淡入淡出。
3. **转场像调味料，不是主菜**：straight cut 处理 95% 的剪辑；叠化不超过 12 帧；花哨转场（星形擦除、旋转）显业余。
4. **人声为王**：口播/旁白类视频，一切声音让人声；BGM 和音效都不能盖过人声。
5. **配乐别先混**：先定人声，再压配乐，是「音乐盖住对白」的第一大元凶的解药。
6. **字幕宁短勿长**：单句 ≤ 16 字、一行放得下；避免两行遮挡画面；字幕区纵向 80%–95%。
7. **专有名词不拆断**：品牌名、人名、英文词在任何换行处保持完整。
8. **音效/配乐去版权风险**：只用 CC0 库（如 OpenFilm 免费库）或自备素材，禁未授权音乐。
9. **先审片再交付**：导出前用审片视角过一遍字幕遮挡、配音节奏、音画同步、响度。
10. **留足安全余量**：峰值不超 -1 dBTP，避免削波。

## 三、剪辑常识参数（音频音量参考）

### 声音层级（4 层设计，从高到低）

| 层 | 内容 | 建议电平 |
|---|---|---|
| 1 · 人声/对白 | 口播、旁白、对话 | 峰值 **-12 ~ -6 dBFS**，响度约 -16 ~ -18 LUFS |
| 2 · 音效/拟音 | 转场、强调、按钮 | **-18 ~ -12 dB**（不超过人声） |
| 3 · 环境音 | 底噪、房间音 | -28 ~ -24 dB |
| 4 · 配乐 BGM | 背景音乐 | **-22 ~ -18 dB**（人声下自动压得更低） |

### 关键平衡规则

- **人声比 BGM 高 6-8 dB**（分轨处理：人声归人声、BGM 归 BGM、音效归音效，各自调增益，最后看总轨）。
- **BGM 在人声下**：约 -20 ~ -30 dB（「感受到它，而不是听清它」）。
- **音效不超过人声**：转场音效轻柔（约 -23 LUFS），强调音效有存在感但不刺耳。

### 响度标准化（成片导出）

| 平台 | 平均响度 | 峰值 |
|---|---|---|
| B站 / YouTube（长视频） | **-14 LUFS** | ≤ -1 dBTP |
| 抖音 / 快手 / 视频号 | **-16 LUFS** | ≤ -1 dBTP |
| 院线 / 电视 | -24 LUFS | ≤ -2 dBTP |

> 本项目课程视频按 **-14 LUFS、峰值 ≤ -1 dBTP** 输出（在线长视频标准）。

### 本课实际数值（供复现参考）

- 配音（人声）：-18.1 LUFS
- 配乐（BGM）：volume 0.3（约为人声的 30%，≈ -28 LUFS 以下）
- 音效：降到约 -23 LUFS（比人声低约 5 dB）
